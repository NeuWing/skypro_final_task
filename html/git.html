Git и команды терминала

  • ls - расшифровывается как "List files in the directory", что переводится как "перечислить все файлы в папке" или "вывести на экран список файлов в папке".
  • cd - расшифровывается как "Change directory", что переводится как "сменить папку" или "перейти в другую папку".
  • pwd — расшифровывается как "Print Working Directory", что переводится как "показать текущую рабочую директорию".
  • mkdir - расшифровывается как "Make directory", что переводится как "создать папку".
  • mv - расшифровывается как "Move", что переводится как "переместить", "передвинуть". С помощью нее можно переместить, переименовать файл.
  • rm — расшифровывается как "Remove", что переводится как "удалить", используется для удаления файлов.

Основные команды Git

  • git init — создание нового локального репозитория.
  • git clone — копирование удалённого репозитория.
  • git status — отображение состояния рабочего каталога.
  • git add — добавление изменений в индекс.
  • git commit -m "сообщение" — сохранение изменений в репозитории.
  • git log — просмотр истории коммитов.
  • git push — отправка коммитов в удалённый репозиторий.
  • git pull — получение изменений из удалённого репозитория и их интеграция в текущую ветку.
  • git branch — просмотр списка веток.
  • git checkout — переключение между ветками.
